# WorkShake brand direction

The supplied palette reference was translated into these primary colors:

- Forest — `#577958`
- Olive — `#819347`
- Sage — `#D0D6AA`
- Pollen — `#D5D493`
- Sun — `#F2E08C`
- Mist — `#E6E9F0`

The interface uses a darker derived forest (`#24352A`) only where necessary for readable body text and WCAG contrast.

## Visual direction

WorkShake should feel useful, friendly and grounded rather than corporate or overly glossy. The floral palette becomes a clean marketplace system through large rounded surfaces, quiet grid textures, warm yellow calls to action and green trust cues.

The project intentionally contains visual placeholders instead of stock photos so final photography can be supplied later without replacing layout code.
